# 联网搜索

本指南启用 X-Talk 桌面应用内置的联网搜索工具；假定应用已按[模型配置](../../tutorial/desktop_app/model_configuration.zh.md)加载了模型配置并运行。

该工具通过 [Serper](https://serper.dev/) 获取搜索结果，需要一个 Serper API Key。

## 配置密钥

1. 打开右上角的**设置与诊断**；
2. 在**服务凭据**中找到 **Serper 联网搜索**；
3. 点击**配置**，输入 Serper API Key 并保存；
4. 点击**应用并重启本地服务**。

密钥会保存在操作系统的凭据管理器中，不会写入模型配置文件。
