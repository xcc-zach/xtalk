# Web Search

This guide enables the built-in web search tool of the X-Talk desktop app; it assumes the app already runs with a model configuration from [Model Configuration](../../tutorial/desktop_app/model_configuration.md).

The tool retrieves results through [Serper](https://serper.dev/) and needs a Serper API key.

## Configure the API key

1. Open **Settings and diagnostics** in the upper-right corner.
2. Find **Serper Web Search** under **Service credentials**.
3. Select **Configure**, enter the Serper API key, and save it.
4. Select **Apply and restart local service**.

The key is stored in the operating system credential manager and is not written to the model configuration file.
