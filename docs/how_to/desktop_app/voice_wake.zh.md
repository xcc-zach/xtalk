# 语音唤醒

本指南在 X-Talk 桌面应用中开启免手动的对话唤起；假定应用已按[模型配置](../../tutorial/desktop_app/model_configuration.zh.md)加载了模型配置并运行。

语音唤醒启用后，X-Talk 桌面应用会在没有进行对话时监听唤醒词。检测到唤醒词后，应用会开始一个新的语音对话；对话期间会暂停唤醒词监听，并在对话结束后恢复。

## 配置语音唤醒

1. 打开右上角的**设置与诊断**；
2. 展开**语音唤醒**；
3. 开启**语音唤醒**；
4. 在**唤醒词**中输入要使用的中文或英文短语；
5. 在**阈值**中设置 `0` 到 `1` 之间的数值。

阈值越高，触发条件越严格；阈值越低，唤醒更灵敏，但也更容易误触发。修改唤醒词或阈值后，应用会自动更新监听设置。
