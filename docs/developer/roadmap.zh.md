# 架构

## 方案1:回合检测+文本自回归微调

回合检测模型输入对话历史和累计的ASR内容，输出start/stop/do_nothing

异步工具调用完成触发start

微调文本自回归模型，支持异步工具调用，收到start开始生成，根据TTS进度逐字更新历史，同时新的ASR内容到来时实时插入历史，保持继续生成；收到stop时停止生成

## 方案1.5:回合检测做进文本自回归微调

微调的文本自回归模型在认为不需要生成时直接输出一个end，但是end从不进对话历史

可选silence状态输入

## 进阶：联合编码声学信息

最近一段时间的音频编码接入LLM；输出额外声学token，用于控制全双工TTS副语言信息

## 方案2:多流建模

架构同 minicpmo4.5，移除visual部分，加入工具调用输出

5次forward token流
```
[
  <unit>,
  A[1,1] ... A[1,n1],
  <|listen|>,
  </unit>,

  <unit>,
  A[2,1] ... A[2,n2],
  <|listen|>,
  </unit>,

  <unit>,
  A[3,1] ... A[3,n3],
  <|speak|>,
  T1 T2 T3 T4 T5 T6,
  <|chunk_eos|>,
  </unit>,

  <unit>,
  A[4,1] ... A[4,n4],
  <|speak|>,
  T7 T8 T9 T10 T11 T12,

  <unit>,
  A[5,1] ... A[5,n5],

  T13 T14 T15 T16,

  </unit>
]
```
